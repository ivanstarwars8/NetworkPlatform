# CONTRIBUTING

## Сторонние изменения пока не принимаются

Лицензия проекта не выбрана (ADR-0006). Пока её нет, сторонние изменения не принимаются и репозиторий не публикуется: после первого стороннего изменения смена лицензии потребует согласия каждого автора. Вопрос о CLA или DCO тоже не решён (ADR-0006 §6, вопрос 2).

Этот документ описывает правила, которые уже действуют для тех, кто работает в репозитории сейчас, и которые будут действовать для всех после решения.

## Перед началом

1. Прочитать `CLAUDE.md` и `STATUS.md`.
2. Найти ADR, который относится к изменению. Если изменение ему противоречит — сначала новый ADR.

## Требования к изменению

- **Никаких заглушек, выдаваемых за работу.** Модуль, каталог и запись в `Package.swift` появляются вместе с настоящим кодом и хотя бы одним тестом (ADR-0004 §2.2).
- **Сборка и тесты.** `swift build` и `swift test` проходят. Если проверить негде, файл получает заголовок `UNVERIFIED` и строку в `STATUS.md`; ошибки сборки и тестов не скрываются.
- **Границы модулей.** Общие модули не импортируют адаптеры движков; типы и имена полей движков не выходят за адаптер (ADR-0001 §5, ADR-0004 §2.3).
- **Потери не молчат.** Импорт и компиляция конфигурации возвращают отчёт (ADR-0002 §6).
- **Секреты.** Не попадают в журнал, тестовые данные и репозиторий. Ключи подписи, идентификаторы команд, токены — никогда в git.
- **Входные данные ограничены по размеру**; ограничение проекта называется ограничением проекта.
- **Зависимости.** Новая зависимость — только с проверенной лицензией и записью в `THIRD_PARTY_NOTICES.md`. Сейчас у Swift-пакета внешних зависимостей нет.
- **Чужой код.** Из GPL-референсов (sing-box, sing-box-for-apple, OneXray, Karing) и из hiddify ничего не копируется. Из libXray и WireGuardKit (MIT) — можно, с сохранением уведомлений (ADR-0006 §5).
- **Бинарники.** XCFramework и другие собранные артефакты в git не добавляются.

## Утверждения в документах

Каждый факт помечается **[V]** (видно в исходнике или официальном документе, указан путь) либо **[U]** (по памяти, из вторичного источника, не подтверждено сборкой). Номера версий, лимиты и имена API не придумываются.

## Язык и стиль

- Документы — на русском; код, идентификаторы и комментарии в коде — на английском.
- Swift: публичный API документирован; ошибки, выходящие из модуля, типизированы.
- Тесты — XCTest, рядом с модулем: `Packages/<Name>/Tests`.

## Изменение считается завершённым, когда

Выполнены все пункты Definition of Done из `CLAUDE.md`, а `STATUS.md` и `CHANGELOG.md` обновлены.

## Уязвимости

Не через публичные задачи: см. `SECURITY.md`.
