# SECURITY

## Состояние

Выпусков нет, приложение не собрано, пользователей нет. Поддерживаемых версий, для которых выпускались бы исправления, пока не существует.

## Как сообщить об уязвимости

**Канал для закрытых сообщений ещё не назначен.** Репозиторий не опубликован; адрес и ключ для шифрованной переписки владелец проекта укажет здесь до первой публикации. Это условие выхода из Phase 10 (`ROADMAP.md`).

До тех пор, если у вас есть доступ к репозиторию, — сообщайте владельцу напрямую, не через открытые задачи.

Намеченный порядок после публикации:

1. Сообщение по закрытому каналу с описанием, условиями воспроизведения и оценкой последствий.
2. Подтверждение получения и первичная оценка.
3. Исправление, затем согласованное раскрытие с указанием автора сообщения, если он не против.

Сроки ответа не обещаются, пока не назначены ответственные.

## Что считается уязвимостью

- утечка секретов профиля (UUID, ключи, пароли, токены подписок) — в журнал, диагностический пакет, отчёт о сбое, резервную копию;
- трафик или DNS-запросы мимо туннеля, когда пользователь настроил иное; туннель, который поднят, но ничего не пересылает;
- выполнение кода или отказ в обслуживании через импортируемые данные: ссылку, подписку, конфиг, набор правил;
- доступ постороннего процесса или устройства к каналу управления туннелем;
- обход проверки TLS, не запрошенный пользователем явно;
- уязвимости в сборочной цепочке движков.

Ошибки самих sing-box и Xray-core сообщаются их авторам; нам — если они затрагивают то, как движок встроен.

## Принципы

Подробно — `Documentation/Security/THREAT_MODEL.md` и ADR-0003 §4.

- секреты хранятся в Keychain; расширение их оттуда не читает;
- приложение и расширение не общаются через сетевые сокеты;
- набор entitlements минимален;
- входные данные ограничены по размеру;
- нет удалённого управления поведением приложения и скрытой телеметрии;
- версии движков и тулчейна закрепляются по SHA; собранные бинарники в git не хранятся.

Это намерения и правила для кода. Проверенных реализаций за ними пока нет: см. `STATUS.md`.

## Чего в репозитории быть не должно

Ключей подписи, профилей provisioning, идентификаторов команд, токенов, рабочих конфигураций серверов. Найденное — повод для сообщения по этому документу.
