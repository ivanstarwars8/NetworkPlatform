# NetworkPlatform

Открытая сетевая платформа (прокси/VPN-клиент) для iOS, iPadOS, macOS, tvOS и visionOS. Движки sing-box и Xray-core подключаются как сменные; профили, маршрутизация, конфигурация и управление туннелем — собственный код на Swift.

Рабочее название. Имя продукта не выбрано; имена движков в нём использоваться не будут (ADR-0006, правило 7).

## Состояние на 2026-11-24

**Phase 0 (исследование) завершена, Phase 1 начата. Рабочего приложения нет.**

- Туннель ни разу не поднимался. Ни один движок не собран и не подключён.
- Код приложения и расширения Packet Tunnel написан на Linux и **ни разу не компилировался**.
- Swift-пакет с четырьмя модулями логики собран и протестирован на Linux в контейнере (Swift 5.10.1, 251 тест из 251 проходит); на платформах Apple пакет ещё не собирался — см. `STATUS.md`.
- Для установки туннеля на устройство нужны Mac с Xcode, платный аккаунт Apple Developer с возможностью Network Extension и физическое устройство. Ничего из этого сейчас нет.

Подробно, с разделением на «сделано / не проверено / заблокировано»: [`STATUS.md`](STATUS.md).

Этот файл не перечисляет функций продукта: их пока нет. План — в [`ROADMAP.md`](ROADMAP.md).

## Сборка и тесты

Чистые Swift-модули не зависят от движков и от Xcode-проекта:

```sh
swift build
swift test
```

Нужен Swift 5.9 или новее (`// swift-tools-version:5.9` в `Package.swift`). Внешних зависимостей у пакета нет.

Те же две команды выполняет CI (`.github/workflows/ci.yml`) на macOS и в Linux-контейнере. Workflow написан, но ни разу не запускался: репозиторий не опубликован.

Приложение и расширение этой командой не собираются. Для них намечен путь `cd Apps && xcodegen generate` на Mac; он не проверен — см. заголовки файлов в `Apps/` и `Extensions/`.

## Архитектура в пяти строках

1. Один движок на процесс Packet Tunnel; каждый движок — отдельный артефакт в отдельном расширении (ADR-0001).
2. Приложение не линкует Go: разбор профилей и компиляция конфигурации — на Swift (ADR-0001, ADR-0002).
3. Источник истины — собственная типизированная модель; конфиг движка — результат компиляции с отчётом о потерях (ADR-0002).
4. Пакеты не проходят через Swift; приложение и расширение общаются через `sendProviderMessage`, без сетевых сокетов (ADR-0003).
5. Минимальные версии: iOS/iPadOS 17.0, macOS 14.0, tvOS 17.0, visionOS 1.0; visionOS — экспериментальный уровень (ADR-0005).

Все пять решений приняты по чтению исходников и документации и условны до проверки на Mac (ADR-0001 §7).
